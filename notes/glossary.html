1. Temel Makine Öğrenmesi Kavramları

Machine Learning

Machine Learning (ML), bilgisayarın açıkça her kuralı programlamak yerine veriden bir örüntü öğrenmesini sağlayan yöntemler bütünüdür.

Klasik programlama: Rules + Data → Output
Machine Learning: Data + Expected Output → Model

Model daha sonra:

New Data → Model → Prediction

Model

Model, veriden öğrenilmiş parametreler ve matematiksel işlemlerden oluşan tahmin mekanizmasıdır.

Örneğin basit bir linear model:
y = wx + b

Burada:
- w → weight
- b → bias
- x → input
- y → prediction

Training sırasında model w ve b değerlerini öğrenir.

Parameter

Modelin training sırasında öğrendiği değerlerdir.

Örneğin:
y = wx + b

w ve b parametredir.

Ne kadar çok parametre varsa modelin öğrenebileceği fonksiyon ailesi genellikle o kadar büyür.

Hyperparameter

Modelin kendisinin öğrenmediği, training başlamadan önce bizim belirlediğimiz ayarlardır.

Örneğin:
- learning rate
- batch size
- number of layers
- hidden layer size
- number of training steps
Parameter → model öğrenir
Hyperparameter → biz belirleriz

2. Dataset Kavramları

Dataset

Modelin öğrenmesi veya değerlendirilmesi için kullanılan veri kümesidir.

Language modeling'de örneğin:
"hello world"
"machine learning"
"deep learning"
gibi metinlerden oluşabilir.

Training Set

Modelin öğrenmek için kullandığı veri. Model parametrelerini bu veri üzerinden günceller.

Training data
↓
Prediction
↓
Loss
↓
Backpropagation
↓
Parameter update

Dev / Validation Set

Modelin training sırasında değerlendirilmesi ve hyperparameter seçiminde kullanılan veri. Model bu verinin üzerinde doğrudan öğrenmemelidir.

Örneğin:
Train → model learns
Dev → model decisions are evaluated
Test → final evaluation

Test Set

Modelin training ve model seçimi tamamlandıktan sonra final performansını ölçmek için kullanılan veri. Test setine mümkün olduğunca en son bakılır.

Train / Dev / Test Split

Dataset'in farklı amaçlarla ayrılmasıdır.

Örneğin:
80% → Train
10% → Dev
10% → Test

Ama oran probleme göre değişebilir.

Train → Learn
Dev → Tune
Test → Final evaluation

Data Leakage

Modelin normalde prediction sırasında sahip olmaması gereken bilgilerin training'e sızmasıdır. Bu durum modelin gerçek hayattaki performansını olduğundan iyi gösterebilir.

3. NLP ve Language Modeling

NLP

Natural Language Processing, bilgisayarların insan dilini işlemesini sağlayan alan.

Örnekler:
- text classification
- translation
- summarization
- question answering
- language modeling
- sentiment analysis

Token

Modelin işlediği temel metin birimidir.

Token:
- karakter olabilir
- kelime olabilir
- kelime parçası olabilir
Örneğin:
"hello world"
şu şekilde tokenize edilebilir:
["hello", "world"]

veya karakter seviyesinde:
["h", "e", "l", "l", "o", " ", "w", ...]

Vocabulary

Modelin bildiği bütün tokenların kümesidir.

Örneğin:
Vocabulary:
["a", "b", "c", ..., "z", "."]

27 token varsa:
vocab_size = 27

Token ID

Her token'a verilen sayısal kimliktir.

Örneğin:
"a" → 0
"b" → 1
"c" → 2
...

Model doğrudan "a" veya "hello" ile matematik yapmaz.

Text
↓
Token
↓
Token ID
↓
Tensor

Sequence

Tokenların belirli bir sıradaki dizisidir.

Örneğin:
["the", "cat", "sat"]
bir sequence'dir.

Language modeling'de sıra önemlidir çünkü model context'i sıradan öğrenir.

Context

Modelin mevcut prediction'ı yaparken kullandığı önceki tokenlardır.

Örneğin:
"The cat is"
context ise modelin:
"The cat is ___"
sonraki tokenı tahmin etmesi beklenir.

4. N-Gram

N-Gram

Ardışık n token'dan oluşan parçadır.

n = 1 → unigram
n = 2 → bigram
n = 3 → trigram
Örneğin:
"I love machine learning"
Unigram: "I", "love", "machine", "learning"
Bigram: "I love", "love machine", "machine learning"
Trigram: "I love machine", "love machine learning"

Unigram

Tek tokenlık n-gram. En basit language model yaklaşımıdır. Model sadece tokenların genel görülme sıklığına bakabilir.

Bigram

İki tokenlık n-gram. Bir tokenın kendisinden önce gelen tokena bağlı olduğunu varsayar:

P(x_t | x_{t-1})
Örneğin:
P("cat" | "the")

Trigram

Üç tokenlık n-gram. İki önceki tokenı context olarak kullanır:

P(x_t | x_{t-2}, x_{t-1})
Örneğin:
P("sat" | "the", "cat")

N-Gram Count

Bir n-gram'ın dataset içinde kaç kez görüldüğünü tutar.

Örneğin:
"the cat" → 15
"the dog" → 8

Bu count'lar conditional probability hesaplamak için kullanılabilir.

Conditional Probability

Bir olayın başka bir olaya bağlı olma olasılığıdır.

Language modeling:

P(next token | context)
Örneğin:
P("cat" | "the")

5. Language Model

Language Model

Bir dil dizisindeki tokenların olasılığını modelleyen sistemdir.

Temel görev: Verilen context'e göre bir sonraki tokenın ne olacağını tahmin etmek.

"The cat is"
↓
Model
↓
"sleeping" → probability
"running" → probability
"blue" → probability
...

Modern language model'ler bunu neural network kullanarak yapabilir.

Next-Token Prediction

Language model'in temel görevlerinden biri.

Input:
"The cat"

Target:
"is"

Model:

"The cat" → probabilities for next token

üretir. Training sırasında modelin tahmini gerçek next token ile karşılaştırılır.

6. One-Hot Encoding

One-Hot Vector

Bir tokenı vocabulary içindeki konumuyla temsil eden vektördür.

Vocabulary:
[a, b, c, d]

c:
[0, 0, 1, 0]

Özellikleri:

vector length = vocabulary size
yalnızca bir eleman 1
diğerleri 0

Problem

One-hot representation tokenlar arasındaki anlamsal ilişkileri ifade etmez.

Örneğin:
cat → [1,0,0]
dog → [0,1,0]

Model açısından bu iki tokenın birbirine ne kadar benzediğini doğrudan göstermez. Bu nedenle embedding kullanılır.

7. Embedding

Embedding

Bir token ID'sini öğrenilebilir yoğun bir vektöre dönüştürür.

Token ID
↓
Embedding
↓
Dense vector
Örneğin:
"cat" → [0.21, -0.44, 0.83, ...]

Embedding vector'ünün boyutu vocabulary size olmak zorunda değildir.

Örneğin:
vocab_size = 27
embedding_dim = 10
olabilir.

Embedding Dimension

Her tokenın embedding vector'ünde kaç sayı olduğunu belirtir.

Örneğin:
embedding_dim = 100
ise:
token → 100-dimensional vector
olur.

Embedding Matrix

Tüm token embedding'lerinin bulunduğu matrix.

Örneğin:
vocab_size = 27
embedding_dim = 10
ise:
Embedding matrix shape:

27 × 10

Her satır bir tokenın embedding'idir.

8. Neural Network

Neural Network

Input'u parametreli matematiksel işlemlerden geçirerek output üreten modeldir.

Input
↓
Linear Layer
↓
Activation
↓
Linear Layer
↓
Output

Neuron

Bir neuron kabaca weighted sum + bias + activation işlemidir.

z = w₁x₁ + w₂x₂ + ... + b
output = activation(z)

Layer

Bir neural network'teki işlem katmanıdır.

Input
↓
Hidden Layer
↓
Hidden Layer
↓
Output Layer

Hidden Layer

Input ve output arasında bulunan layer. Modelin input ile output arasındaki daha karmaşık ilişkileri öğrenmesini sağlar.

MLP

Multi-Layer Perceptron. Birden fazla fully-connected/linear layer'dan oluşan neural network türüdür.

Embedding
↓
Linear
↓
Tanh
↓
Linear
↓
Logits

YZ50'deki küçük language model bunun bir örneğidir.

9. Linear Layer

Linear Transformation

Temel olarak:

y = Wx + b

işlemini yapar.

- W → weight matrix
- x → input
- b → bias
- y → output
PyTorch:
nn.Linear(in_features, out_features)

Weight

Modelin input özelliklerine verdiği öğrenilebilir ağırlıklardır. Training sırasında gradient descent ile güncellenir.

Bias

Linear layer'ın output'una eklenen öğrenilebilir değerdir.

y = Wx + b

Bias, modelin yalnızca origin'den geçen fonksiyonlar öğrenmek zorunda kalmasını engeller.

10. Activation Functions

Activation Function

Neural network'e non-linearity ekleyen fonksiyondur.

Eğer activation kullanmazsak:

Linear
↓
Linear
↓
Linear

gibi birçok linear layer'ın birleşimi yine tek bir linear transformation'a indirgenebilir. Activation sayesinde network daha karmaşık fonksiyonlar öğrenebilir.

11. Sigmoid

Sigmoid

Bir değeri 0 ile 1 arasına sıkıştıran S-shaped activation function.

\sigma(x) = \frac{1}{1+e^{-x}}
Örnek:
sigmoid(-5) ≈ 0.007
sigmoid(0) = 0.5
sigmoid(5) ≈ 0.993

Davranışı:

x → -∞ ⇒ sigmoid(x) → 0
x = 0 ⇒ sigmoid(x) = 0.5
x → +∞ ⇒ sigmoid(x) → 1

Kullanım

Özellikle binary classification output'unda kullanılabilir.

logit
↓
sigmoid
↓
0...1
Örneğin:
logit = 2.2
sigmoid(2.2) ≈ 0.90

Bu değer binary classification'da pozitif sınıfa ait probability olarak yorumlanabilir.

Problem: Saturation

Input çok büyük veya çok küçük olduğunda sigmoid yaklaşık 0 veya 1 olur. Bu bölgelerde gradient çok küçülür.

Bu:

vanishing gradient

problemine katkıda bulunabilir.

12. Tanh

Tanh

Input'u -1 ile 1 arasına sıkıştıran activation function.

tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}

Önemli değerler:

tanh(-∞) → -1
tanh(0) = 0
tanh(+∞) → +1

Sigmoid ile karşılaştırma:

Sigmoid → 0 ... 1
Tanh → -1 ... 1

Saturation

Tanh da büyük |x| değerlerinde saturate olur.

çok negatif → -1
0 → 0
çok pozitif → +1

Bu bölgelerde gradient küçülebilir.

13. ReLU

ReLU

Rectified Linear Unit

ReLU(x) = max(0,x)

Yani:

x < 0 → 0
x > 0 → x
Örneğin:
ReLU(-3) = 0
ReLU(2) = 2

Sigmoid ve tanh'a göre hidden layer'larda gradient problemlerini azaltması nedeniyle yaygın kullanılır.

14. Logits

Logit

Modelin output layer'ından çıkan ham skor. Henüz probability değildir.

Örneğin vocabulary 4 token içeriyorsa:
logits:

[2.1, 0.3, -1.2, 3.5]

Model her token için bir skor üretmiştir. Daha sonra:

Logits
↓
Softmax
↓
Probabilities

Logit vs Probability

Çok önemli ayrım:

Logit → raw score
Probability → normalized value between 0 and 1

Logits:

negatif olabilir
1'den büyük olabilir
toplamları 1 olmak zorunda değildir

Probability:

0 ≤ p ≤ 1
tüm sınıfların toplamı 1

15. Softmax

Softmax

Bir logits vector'ünü probability distribution'a dönüştürür.

softmax(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
Örneğin:
Logits:
[2.0, 1.0, 0.0]

Softmax yaklaşık olarak:
[0.665, 0.245, 0.090]
üretir.

Toplam:

0.665 + 0.245 + 0.090 ≈ 1

Language Model'de

Vocabulary'deki her token için probability üretir.

logits
↓
softmax
↓
P("the")
P("cat")
P("dog")
P("is")
...

16. Loss Function

Loss

Modelin prediction'ının gerçek target'tan ne kadar uzak olduğunu ölçen sayı.

Genel fikir:

Prediction
↓
Loss
↑
Target

Training'in amacı genellikle loss'u minimize etmektir.

17. Cross-Entropy Loss

Cross-Entropy Loss

Classification ve language modeling'de çok kullanılan loss function. Model doğru class'a düşük probability verirse yüksek loss oluşur.

Basit durumda:

L = -\log(p_{correct})
Örneğin:
p(correct) = 0.9
ise:
loss ≈ 0.105
Ama:
p(correct) = 0.01
ise loss çok daha büyüktür.

Yani: Model doğru cevaptan ne kadar eminse, loss o kadar küçülür.

18. Negative Log Likelihood (NLL)

Negative Log Likelihood (NLL)

Bir olayın probability'sinin negatif logaritmasını kullanır.

NLL = -\log(p)

Language modeling'de modelin gerçek next token'a verdiği probability üzerinden hesaplanabilir. Cross-entropy ile çok yakından ilişkilidir.

19. Gradient

Gradient

Loss'un model parametrelerine göre hangi yönde ve ne kadar değiştiğini gösterir.

Bir parameter θ için:

\frac{\partial L}{\partial \theta}

gradient'tir.

Sezgisel olarak: "Bu parametreyi biraz değiştirirsem loss hangi yönde değişir?"

20. Derivative

Derivative

Bir fonksiyonun input'u değiştiğinde output'un ne kadar değiştiğini ölçer.

Örneğin:
y = x^2
ise:
dy/dx = 2x

Neural network training'in temelinde derivative vardır.

21. Backpropagation

Backpropagation

Loss'tan başlayarak network içinde geriye doğru gidip her parametrenin gradientini hesaplama sürecidir.

Input
↓
Forward Pass
↓
Prediction
↓
Loss
↓
Backpropagation
↓
Gradients

Önemli: Backpropagation parametreleri güncellemez; gradientleri hesaplar.

22. Gradient Descent

Gradient Descent

Gradientleri kullanarak parametreleri loss'u azaltacak yönde güncelleme yöntemidir.

\theta_{new} = \theta_{old} - \eta \nabla L
Burada:
- θ → parameter
- η → learning rate
- ∇L → gradient
Forward
↓
Loss
↓
Backward
↓
Gradient
↓
Gradient Descent
↓
Parameter Update

23. Learning Rate

Learning Rate

Her parameter update'inin ne kadar büyük olacağını belirler.

θ ← θ - learning_rate × gradient

Çok büyük learning rate:

overshooting
unstable training

Çok küçük learning rate:

very slow training

24. Optimizer

Optimizer

Gradientleri kullanarak model parametrelerini güncelleyen algoritmadır.

Örnek:
- SGD
- Adam
- AdamW
PyTorch:
optimizer.step()

Genel training loop:

optimizer.zero_grad()

output = model(x)
loss = loss_fn(output, target)

loss.backward()
optimizer.step()

27. Batch

Batch

Modelin tek bir update sırasında birlikte işlediği örnek grubudur.

Örneğin:
dataset = 10,000 examples
batch_size = 32

Model her iteration'da 32 örnek işleyebilir.

28. Batch Size

Batch Size

Bir batch'teki örnek sayısıdır.

batch_size = 32
→ model aynı anda 32 training example işler.

Batch size büyüdükçe:

memory kullanımı artabilir
gradient daha fazla örneğin ortalamasını temsil eder
training davranışı değişir

29. Epoch

Epoch

Modelin training datasetinin tamamını bir kez görmesi.

Örneğin:
10,000 examples
batch_size = 100
ise yaklaşık:
100 batches = 1 epoch

30. Iteration / Step

Iteration / Step

Modelin bir batch üzerinde bir training update'i gerçekleştirmesidir.

Kabaca:

1 batch → 1 step

Bir epoch'taki step sayısı yaklaşık:

\frac{dataset\ size}{batch\ size}

31. Shuffle

Shuffle

Training örneklerinin sırasını rastgele değiştirmektir. Özellikle dataset'teki örnekler belirli bir sırada gruplanmışsa önemlidir.

Örneğin:
Food
Food
Food
Food
Sports
Sports
Sports

yerine:

Sports
Food
Sports
Food
...

gibi daha karışık batch'ler oluşturulabilir. Amaç modelin batch'ler arasında daha çeşitli örnekler görmesini sağlamaktır.

32. Sampling

Sampling

Modelin probability distribution'ından bir sonraki tokenı seçme işlemidir.

Örneğin model:
cat → 0.60
dog → 0.30
car → 0.10
üretiyorsa sampling sonucunda:
cat

seçilebilir ama dog veya car seçilmesi de mümkündür. Bu, her zaman en yüksek probability'yi seçmekten farklıdır.

33. Overfitting

Overfitting

Modelin training data'sını çok iyi öğrenmesine rağmen yeni/verilmemiş data üzerinde kötü performans göstermesi.

Tipik:

Train loss ↓↓↓
Dev loss ↓ sonra ↑

Model training examples'a fazla uyum sağlamıştır.

34. Underfitting

Underfitting

Modelin training data'sını bile yeterince öğrenememesi.

Örneğin:
Train loss → yüksek
Dev loss → yüksek

Model yeterince güçlü olmayabilir veya yeterince train edilmemiş olabilir.

35. Generalization

Generalization

Modelin training sırasında görmediği yeni veriler üzerinde de iyi performans göstermesidir.

Amaç:

Memorization
↓
yerine
↓
Generalization

36. Saturation

Saturation

Activation function'ın belirli bölgelerde output'unun neredeyse sabit hale gelmesidir.

Sigmoid:

x → -∞ → 0
x → +∞ → 1

Tanh:

x → -∞ → -1
x → +∞ → 1

Bu bölgelerde derivative çok küçülür.

Sonuç:

small gradient
↓
small updates
↓
vanishing gradient

37. Vanishing Gradient

Vanishing Gradient

Gradientlerin network içinde çok küçülmesi problemidir. Özellikle sigmoid/tanh gibi saturation gösteren activation'larda ortaya çıkabilir.

Gradient:

1 → 0.5 → 0.1 → 0.01 → 0.001

gibi gittikçe küçülürse erken layer'lar çok az güncellenebilir.

38. Exploding Gradient

Exploding Gradient

Gradientlerin aşırı büyümesi.

1 → 5 → 20 → 100 → 1000

gibi. Training unstable hale gelebilir.

39. Initialization

Initialization

Neural network parametrelerinin training başlamadan önce hangi değerlerle başlatılacağını belirleme işlemidir.

Kötü initialization:

çok büyük activations
çok küçük activations
vanishing gradients
exploding gradients

gibi sorunlara yol açabilir.

40. Kaiming Initialization

Kaiming Initialization

Özellikle ReLU benzeri activation'larla kullanılan weight initialization yöntemidir.

Temel amaç: Layer'lar arasında activation ve gradient ölçeğinin çok fazla büyüyüp küçülmesini engellemek.

Kabaca:

Var(W) \approx \frac{2}{n}
Buradaki n, ilgili layer'ın input fan-in'idir.

41. Batch Normalization

Batch Normalization

Activation'ları batch içerisindeki istatistikleri kullanarak normalize eden yöntemdir.

activation
↓
normalize
↓
scale + shift
↓
next layer

Amaç training'i daha stabil hale getirmek ve uygun koşullarda optimization'ı kolaylaştırmaktır.

Tensor

torch.no_grad()

56. En Önemli Formüller

En Önemli Formüller

Linear layer
y = Wx + b
Sigmoid
\sigma(x) = \frac{1}{1+e^{-x}}
Tanh
tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}
ReLU
ReLU(x) = max(0,x)
Softmax
softmax(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
Cross-Entropy / NLL
L = -\log(p_{correct})
Gradient Descent
\theta_{new} = \theta_{old} - \eta \nabla L
